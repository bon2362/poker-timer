## Отступления и непроверенное

- Выкладка (шаг 6 задачи 10) и задача 11 не выполнялись.
- Снимки публичных и административных экранов на 375 и 1280 px сохранены в `/tmp`, не в репозитории.
- Визуальная сверка вкладки игроков с заполненными данными не выполнена: локальная фикстура не гидратировала список игроков. Пустое состояние проверено.
- Удаление Storage и записи БД не может быть одной транзакцией; маршрут делает компенсационное восстановление при ошибке и показывает русское сообщение.

## Порядок выкладки

1. В Supabase SQL Editor выполнить `supabase/game_history_results_rpc.sql`.
2. После проверки SQL выложить код.
3. На сайте проверить каталог, страницу обеих игр, вход, редактирование результата, загрузку/перенос/удаление фото и сохранённых картинок на компьютере и телефоне.
